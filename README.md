# AI-Powered Career Guidance System
B.Tech CSE 7th Semester Major Project

Personalised career recommendation and skill development platform built with Flask, SQLite, Scikit-learn and Chart.js.

## Features
- Student registration, profile and skill/interest assessment
- Career recommendations with match % (rule-based + Random Forest)
- Skill gap analysis, career comparison, month-wise roadmap
- Project suggestions, resume analyzer, job role explorer
- Progress tracker, AI assistant, admin dashboard

## Run locally
pip install -r requirements.txt
python seed.py
python app.py
Open http://127.0.0.1:5000
